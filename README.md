# Open Source Job Portal

An open-source job portal website designed to connect job seekers with employers.
The platform provides a clean and professional interface for browsing job
listings and exploring opportunities.

## Features
- Modern and responsive user interface
- Job listings displayed dynamically using JavaScript
- Clean navigation with hero and job sections
- Professional and user-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- index.html – Main homepage
- style.css – Styling and layout
- script.js – Dynamic job listing logic

## How to Run
1. Download or clone the repository
2. Open the `index.html` file in any modern web browser

## Future Enhancements
- User authentication for job seekers and employers
- Job posting and application system
- Backend integration with database
